1. Python Virtual Environment එක සැකසීම

මැෂින් එකේ අනිත් ප්‍රොජෙක්ට් වලට බාධාවක් නොවෙන්න මේ ප්‍රොජෙක්ට් එකටම විතරක් වෙනම හුදකලා පරිසරයක් නිර්මාණය කරගන්න python -m venv venv කමාන්ඩ් එක පාවිච්චි කළා.

Git Bash ටර්මිනල් එකේ source venv/Scripts/activate මගින් ඒක ක්‍රියාත්මක (Active) කරගත්තා.

ඊටපස්සේ අපේ Backend එකට අවශ්‍යම කරන Flask (වෙබ් ෆ්‍රේම්වර්ක් එක) සහ PyMySQL (ඩේටාබේස් එකට කනෙක්ට් වෙන ටූල් එක) ඉන්ස්ටෝල් කරගත්තා.

2. MySQL Database එකට සම්බන්ධ වීම (app.py)

VS Code එකේ අලුතින් app.py ෆයිල් එකක් හදලා, ඒකෙ XAMPP හරහා අපි හදපු devdiary_db ඩේටාබේස් එකට කනෙක්ට් වෙන මූලික ලොජික් එක ලිව්වා.

3. Flask Folder Structure එකට ගැලපෙන ලෙස ෆයිල් සැකසීම

Flask සර්වර් එකට තේරුම් ගන්න පුළුවන් වෙන්න අලුත් ෆෝල්ඩර දෙකක් හැදුවා.

අපේ HTML ෆයිල් ඔක්කොම templates ෆෝල්ඩරයට දැම්මා.

CSS සහ Images තියෙන assets ෆෝල්ඩරය සම්පූර්ණයෙන්ම static ෆෝල්ඩරයට ගෙනාවා.

4. Template Inheritance හරහා කෝඩ් එක පිරිසිදු කිරීම (Jinja2)

හැම පේජ් එකකම Navbar එකයි Footer එකයි රිපීට් වෙන එක නවත්තන්න අපි පොදු base.html ෆයිල් එකක් හැදුවා.

ඊටපස්සේ index.html, blog.html වගේ අනිත් හැම ෆයිල් එකකම තිබ්බ උඩ සහ යට කොටස් සම්පූර්ණයෙන්ම මකලා දාලා, {% extends "base.html" %} කියන කමාන්ඩ් එකෙන් ඒ පොදු රාමුව අනිත් පේජ් වලට ගෙන්න ගත්තා. මේ නිසා අපේ කෝඩ් එක මාරම clean වුණා.

5. Routes, Links සහ Assets නිවැරදි කිරීම

app.py එක ඇතුලේ හැම පේජ් එකකටම අදාළව @app.route('/blog') වගේ වෙන වෙනම පාරවල් (Routes) හදලා දුන්නා.

පින්තූර සහ CSS ලෝඩ් වෙන්න ඒවායේ ලින්ක්ස් වල මුලට /static/ එකතු කළා වගේම, Flask වල නියම ක්‍රමය වෙන {{ url_for() }} පාවිච්චි කරලා ලින්ක්ස් ඔක්කොම ඩයිනමික් විදිහට අප්ඩේට් කළා.

6. Active Link Highlighting (request.endpoint)

එකම base.html එකක් පාවිච්චි කරද්දි Navbar එකේ අපි ඉන්න පේජ් එක මොකක්ද කියලා පෙන්නන්න බැරි වුණු අවුල අපි හැදුවා.

request.endpoint කියන Jinja2 කෑල්ල පාවිච්චි කරලා, බ්‍රවුසරේ ලෝඩ් වෙන පේජ් එක අඳුරගෙන ඒකට අදාළ Navbar ලින්ක් එක විතරක් ඔටෝමැටික් තැඹිලි පාටින් සහ බෝල්ඩ් වෙලා (Active) පේන විදිහට ලොජික් එක ලිව්වා.
